## 📋 使用指南

### 快速开始

```bash
# 编译推荐版本（v2）
make

# 编译所有版本
./scripts/build.sh all

# 运行测试
make run-test

# 查看帮助
make help
```

### 版本选择

- **v1 版本**: 适合学习预计算优化原理
- **v2 版本**: 生产环境推荐，性能最优
- **v3 版本**: 实验性版本，用于进一步优化研究

### 性能特点

- **小规模数据**: GPU 有启动开销，建议 n≥32
- **大规模数据**: GPU 显著超越 CPU，n=131072 达到 78-86 微秒
- **内存使用**: 高效的 RAII 管理，零内存泄漏
