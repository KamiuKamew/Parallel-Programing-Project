**关键发现：**

- GPU 首次运行：包含内存分配、kernel 编译、数据传输等开销
- 性能拐点：需要找到 GPU 开始超越 CPU 的数据规模

### Lab2 三步法的成功应用

1. **第一步：基础串行版本** (~1.0ms) ✅
2. **第二步：重构便于并行** (~1.5ms) ✅

### 原根理论的实际应用

- **4 阶原根**：omega=22，适用于 n=4 的 NTT
- **8 阶原根**：omega=33，适用于 n=8 的 NTT
- **重要发现**：omega^2 = 22，解释了为什么 22 只是 4 阶原根

### CUDA 编程最佳实践

- **统一线程映射**：`tid → (block_id, k, j)` 坐标转换
- **Grid/Block 配置**：512 blocks × 256 threads = 131072 线程
- **内存管理模式**：RAII 包装器 + 异常安全
